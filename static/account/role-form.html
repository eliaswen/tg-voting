Staging only: you can set your role to any integer for testing.

Roles are set with an integer, where each bit represents a permission level. This allows up to 64 different roles.
For instance, an account may hold both election minister and census minister permissions, if required. The census minister permission has a value of 4. The election minister permission has a value of 8. The default role is 0. A value of 32 gives you superadmin privileges, allowing you to edit anything.
